# ManGo!

Nueva versión de ManGo!, construida desde cero.

## Objetivo

Construir una aplicación web moderna, mantenible y segura para la gestión de negocios, utilizando PHP y MySQL sin depender de un framework de aplicación.

## Filosofía

Este proyecto se desarrolla desde cero tomando como referencia la versión anterior de ManGo!, pero sin mantener su arquitectura ni su código.

La versión anterior sirve como referencia funcional y de negocio.

## Tecnologías

- MySQL
- HTML
- CSS
- JavaScript
- Composer
- Git
